## O projektu

_Krátce popište svůj projekt – čemu se věnuje, co nabízí a jaký problém řeší?_

`Tento projekt se bude věnovat fitness coachingu. Bude nabízet služby, jako například jídelníček, tréninkový plán, kontroly a osobní tréninky. Problém řeší ten, že v tomto odvětví coachingu je hodně lidí, co nemají dostatek vědomostí, takže si myslím že bych měl co nabídnout. `
